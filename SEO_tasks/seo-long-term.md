## Prerequisites: Complete ALL previous priority tasks

## Weekly Tasks

### Every Monday: Content Audit & Planning

#### Task A1: Review Analytics
1. Open Google Analytics
2. Go to Reports > Engagement > Pages and screens
3. Document these metrics for the past week:
   - Page views per page
   - Average engagement time
   - Bounce rate
   - Conversion events
4. Create spreadsheet: `Weekly_SEO_Report_[DATE].xlsx`
5. Compare to previous week
6. Identify top 3 performing pages and bottom 3

#### Task A2: Search Console Review
1. Open Google Search Console
2. Go to Performance report
3. Document:
   - Total impressions
   - Total clicks
   - Average CTR
   - Average position
4. Export queries report
5. Identify:
   - New keywords appearing
   - Keywords losing position
   - High impression, low CTR keywords

#### Task A3: Plan Weekly Blog Post
1. Based on analytics, choose topic that addresses:
   - High-search, low-competition keywords
   - Customer FAQ from the week
   - Seasonal/trending topics
2. Create content brief:
   - Target keyword
   - Search intent
   - Outline with H2/H3 structure
   - Internal links plan
   - Image requirements

### Every Wednesday: Content Creation

#### Task B1: Write Blog Post
1. Minimum 1000 words
2. Follow this EXACT structure:
   - Title with primary keyword
   - Introduction (100-150 words) with keyword in first paragraph
   - 4-6 H2 sections
   - 2-3 H3 subsections under each H2
   - Conclusion with CTA
3. Include:
   - 5-7 natural keyword uses
   - 3-5 internal links
   - 1-2 external authoritative links
   - 4+ images with descriptive alt text

#### Task B2: Optimize Images
1. For EACH image:
   - Resize to max 1200px width
   - Convert to WebP format
   - Compress to under 150KB
   - Name descriptively: `topic-keyword-description-01.webp`
2. Create alt text following pattern:
   - `[Primary keyword] - [specific description] at RPM Auto`

#### Task B3: Create Meta Data
1. Title tag (55-60 characters):
   - Format: `[Primary Keyword] | [Secondary Keyword] | RPM Auto`
2. Meta description (155-160 characters):
   - Include primary keyword
   - Add compelling CTA
   - Mention location if relevant
3. URL slug:
   - All lowercase
   - Hyphens between words
   - Include primary keyword
   - Max 5 words

### Every Friday: Publishing & Optimization

#### Task C1: Publish Blog Post
1. Log into admin panel
2. Create new post with all content
3. Set categories and tags
4. Add featured image
5. Preview on mobile and desktop
6. Publish and verify live

#### Task C2: Internal Link Building
1. Find 3-5 relevant existing pages
2. Add contextual links to new post
3. Update those pages with links TO new post
4. Document all internal links added

#### Task C3: Social Sharing
1. Create social media posts:
   - LinkedIn: Professional angle
   - Facebook: Community focus
   - Instagram: Visual highlight
2. Include link to blog post
3. Schedule for optimal times

## Monthly Tasks

### First Monday: Technical SEO Audit

#### Task D1: Crawl Website
1. Use Screaming Frog or similar tool
2. Export and analyze:
   - 404 errors
   - Redirect chains
   - Missing meta descriptions
   - Duplicate content
   - Image optimization issues
3. Create fix list with priorities

#### Task D2: Page Speed Analysis
1. Test 10 key pages on PageSpeed Insights
2. Document scores for:
   - Mobile performance
   - Desktop performance
   - Core Web Vitals
3. If any score below 90:
   - Identify specific issues
   - Create optimization plan
   - Implement fixes within week

#### Task D3: Mobile Usability
1. Test on real devices:
   - iPhone (Safari)
   - Android (Chrome)
   - iPad (Safari)
2. Check:
   - Touch target sizes
   - Text readability
   - Horizontal scrolling
   - Pop-up behavior
3. Document any issues found

### Second Monday: Competitor Analysis

#### Task E1: Identify Top 3 Competitors
1. Search main keywords:
   - "luxury cars Vaughan"
   - "exotic cars Toronto"
   - "premium auto dealer GTA"
2. Note top 3 competing dealerships
3. Document their:
   - Domain authority
   - Estimated traffic
   - Top ranking keywords

#### Task E2: Content Gap Analysis
1. Use SEMrush or Ahrefs
2. Find keywords competitors rank for that you don't
3. Create list of:
   - Quick win opportunities (low difficulty)
   - Long-term targets (high value)
   - Content ideas from their top pages

#### Task E3: Backlink Opportunities
1. Analyze competitor backlinks
2. Identify:
   - Local directories they're in
   - Industry associations
   - Media mentions
   - Partnership opportunities
3. Create outreach list

### Third Monday: Local SEO Enhancement

#### Task F1: Google Business Profile Optimization
1. Log into Google Business Profile
2. Update:
   - Add 5+ new photos
   - Respond to ALL reviews
   - Post weekly update
   - Verify all information correct
3. Check insights for:
   - Search queries
   - Customer actions
   - Phone calls tracking

#### Task F2: Local Citations Audit
1. Check consistency on:
   - Yelp
   - Yellow Pages
   - Auto Trader
   - Cars.com
   - Local chamber of commerce
2. Ensure NAP (Name, Address, Phone) identical everywhere
3. Add business to any missing directories

#### Task F3: Local Content Creation
1. Create location-specific page:
   - "[Service] in [Neighborhood]"
   - Example: "Luxury Car Service in Woodbridge"
2. Include:
   - Local landmarks
   - Driving directions
   - Parking information
   - Local testimonials

### Fourth Monday: Conversion Optimization

#### Task G1: A/B Testing Setup
1. Choose one element to test:
   - CTA button color
   - Headline text
   - Form fields
   - Page layout
2. Set up test in Google Optimize
3. Run for minimum 2 weeks
4. Document results

#### Task G2: User Experience Review
1. Record user sessions with Hotjar
2. Analyze:
   - Where users click
   - How far they scroll
   - Where they abandon
3. Identify 3 improvements
4. Implement changes

#### Task G3: Lead Quality Analysis
1. Review all form submissions
2. Categorize by:
   - Source
   - Quality
   - Conversion rate
3. Optimize forms/pages with low-quality leads

## Emergency Response Procedures

### If Organic Traffic Drops 20%+:

1. **Immediate Actions (Within 1 Hour):**
   - Check if site is accessible
   - Verify analytics tracking working
   - Check Search Console for manual actions
   - Look for algorithm update news

2. **Same Day Actions:**
   - Run crawl for technical issues
   - Check major pages for changes
   - Verify no accidental noindex
   - Review recent site changes

3. **Within 48 Hours:**
   - Full technical audit
   - Backlink profile check
   - Competitor analysis
   - Create recovery plan

### If Site Gets Hacked:

1. **Immediate:**
   - Take site offline
   - Change all passwords
   - Contact hosting provider
   - Notify Google via Search Console

2. **Recovery:**
   - Clean infected files
   - Update all software
   - Implement security measures
   - Request review from Google

## Final Notes

1. **Consistency is Key**: SEO success comes from consistent effort over time
2. **Document Everything**: Track all changes and their impact
3. **Stay Updated**: Algorithm changes happen - stay informed
4. **User First**: Always prioritize user experience over search engines
5. **Measure ROI**: Connect SEO efforts to business results

Remember: SEO is a marathon, not a sprint. Focus on sustainable, white-hat practices that build long-term authority and trust.
